# Webpage Clone — Design Template

Generated by `perfect-web-clone-skill` from `https://eatnumi.com/pages/5-reason`.

This project is a **design/layout template** that replicates the structure, layout, color palette, typography and component composition of the source page. Substantive marketing prose, testimonials, and brand-specific phrasing have been replaced with generic Lorem ipsum / placeholder text — only short functional UI labels are retained verbatim. Replace the placeholder copy with your own content before using.

## Sections

- `src/components/Section1.tsx` — Top announcement bar with countdown timer (client component).
- `src/components/Section2.tsx` — Long-form body: hero, 5 reason blocks, stats, before/after grid, testimonials wall, sale pamphlet, footer. Client component (timer).
- `src/components/Section3.tsx` — Footer-area blocks: payment icons, trust strip, predictive search preview, cart drawer preview, newsletter popup. Client component (popup state).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- Original image URLs from the source CDN are used directly (no images downloaded). They are loaded as `<img>` tags with `loading="lazy"`. If the source CDN blocks hot-linking, swap the URLs in each component's `IMG` constant for your own assets.
- Brand colors used: red `#a31621` / `#a6171f`, cream `#fff9f5`, soft pink `#ffeaea`/`#feedee`.
- Tailwind responsive prefixes are applied for mobile/desktop.
